# Public Assets

## Required Images

### Hero Section
- **File:** `hero-image.jpg`
- **Dimensions:** 1920x1080px (minimum)
- **Format:** JPG (optimized)
- **Description:** Main hero background image showing traditional jewelry or craftsmanship
- **Recommendation:** Use a high-quality image of a model wearing traditional jewelry in a cultural setting

## Optimization Tips
1. Compress images using tools like TinyPNG or ImageOptim
2. Use Next.js Image component for automatic optimization
3. Consider WebP format for better compression
4. Use responsive images with srcset for different screen sizes
